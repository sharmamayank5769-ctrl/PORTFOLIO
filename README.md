## ⚙️ Getting Started

Follow these steps to run the portfolio locally:

### 1. Clone the repository

```bash
git clone https://github.com/sharmamayank5769-ctrl/PORTFOLIO.git
```

### 2. Navigate to the project folder

```bash
cd PORTFOLIO/code_base
```

### 3. Open in browser

Simply open `index.html` in any browser:

```bash
# On Linux/Mac
open index.html

# Or just double-click index.html in your file explorer
```

> No build tools or dependencies required — it's pure HTML/CSS/JS!

---

## 🚀 Deployment

You can deploy this portfolio for free using **GitHub Pages**:

1. Go to your repository **Settings**
2. Navigate to **Pages** section
3. Under **Source**, select `main` branch and `/code_base` folder
4. Click **Save** — your site will be live at:

```
https://sharmamayank5769-ctrl.github.io/PORTFOLIO/
```
